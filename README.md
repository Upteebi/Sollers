Базовые проекты для работы в Data Science/Аналитике

Начинающий Data/Product аналитик с крепкой математической базой (теория вероятностей, статистика) и инженерным бэкграундом. 
Самостоятельно реализую аналитические проекты: от сбора данных по API и очистки (EDA) до построения дашбордов и оценки A/B тестов. 
Глубоко понимаю архитектуру приложений, уверенно пишу сложные SQL-запросы и скрипты на Python. 
Интересуюсь продуктовыми метриками, поиском точек роста бизнеса и активно углубляюсь в алгоритмы машинного обучения. 
 НАВЫКИ: 
 Аналитика: A/B тестирование, статистические тесты (Z-тест), продуктовая и маркетинговая аналитика, расчет метрик. 
 Python: Pandas, NumPy, SciPy, statsmodels, SymPy, Jupyter. 
 BI и Визуализация: Power BI, Power Query (fuzzy join, сложные трансформации данных), Data Visualization. 
 Базы данных: PostgreSQL, SQL (многотабличные JOIN, оконные функции, подзапросы, агрегации). 
 Инженерия данных: Получение данных с помощью API, Airflow (базово), Data Preparation.
